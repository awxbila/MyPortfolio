Overview

Project Summary

The project is a personal portfolio website designed to showcase professional skills and experiences in business and technology. It serves as a digital profile for a fresh graduate in Mechanical and Biosystems Engineering who is transitioning into business development and digital product development. The site highlights the creator's background, skills, and organizational achievements.

The primary goal was to create a visually attractive and professional platform to present a biography, business skills, and language competencies to potential employers. It aims to facilitate career opportunities in Account Management or Business Development by providing a centralized location for professional information and a downloadable CV.

The development involved building a responsive web interface using semantic HTML for structure and custom CSS for a modern UI. Implementation included a navigation bar with smooth scrolling, a functional contact form for direct email communication, and mobile-friendly layouts. Version control and public hosting were managed via GitHub and GitHub Pages.

The final deliverable is a fully deployed, responsive personal portfolio website accessible via a custom domain. It features dedicated sections for a profile overview, detailed biography, interactive skill visualizations, and professional experience. The site also includes integrated SEO optimization and a direct contact mechanism.

Methods

Semantic HTML Structure: Implementing tags for better SEO optimization and accessibility.

Responsive Web Design: Creating layouts that adapt to different screen sizes via custom CSS.

DOM Interaction: Using JavaScript to manage mobile menu toggling and interface behavior.

Version Control: Managing project iterations and code history using Git and GitHub.
